# GitHub Pages Setup

This project deploys a **public-safe static site** via GitHub Actions. Personal Bewerbung data is never published.

## Live demo URLs

| Page | URL |
|------|-----|
| **Landing** | https://acimdamero.github.io/ausbildung-scraper/ |
| **Job viewer** | https://acimdamero.github.io/ausbildung-scraper/viewer/ |
| **Bewerbung demo** | https://acimdamero.github.io/ausbildung-scraper/bewerbung-demo/ |

Quick open: `./scripts/open_public.sh`

## What gets published

| Published (public) | Never published (private) |
|--------------------|---------------------------|
| `data/public/index.html` (landing) | `data/bewerbung/` |
| `data/public/viewer/index.html` (job listings) | `user_profile.local.py` |
| `data/public/bewerbung-demo/` (Max Mustermann sample) | `bewerbung_enriched.json` |
| Scraper code & docs on GitHub | Real Anschreiben / emails |

The build script `scripts/build_pages_site.py` copies only public-safe files into `data/public/` before deploy.

## Requirements

1. **Repository must be public** — GitHub Pages on the free plan does not serve `*.github.io` sites from private repos.
2. **Pages source: GitHub Actions** — Settings → Pages → Build and deployment → Source: **GitHub Actions**.

## Enable Pages (one-time)

1. GitHub repo → **Settings** → **Pages**
2. **Build and deployment** → Source: **GitHub Actions**
3. Push to `main` or `cursor/arbeitsagentur-ausbildung-scraper` — workflow `.github/workflows/pages.yml` runs automatically
4. Wait ~1–2 minutes; site appears at the URLs above

## Manual deploy trigger

```bash
git push origin cursor/arbeitsagentur-ausbildung-scraper
# or: Actions → Deploy GitHub Pages → Run workflow
```

## Local preview (same as production)

```bash
python scripts/build_pages_site.py
python -m http.server 8766 --directory data/public
# open http://localhost:8766
```

## Workflow file

Located at `.github/workflows/pages.yml`. It:

1. Checks out the repository
2. Runs `scripts/build_pages_site.py` (landing + viewer copy + demo)
3. Uploads `data/public/` as Pages artifact
4. Deploys to `github-pages` environment

No Node build step — viewer HTML is pre-generated by `scripts/generate_viewer.py`.

## Custom domain (optional)

Settings → Pages → Custom domain → add DNS CNAME to `<username>.github.io`.

## Private version (local only)

For personal Bewerbung with real data:
